# Corner-case catalog: SQL Server → Apache Iceberg (Athena / Glue / Spark)

Each row is a construct where a naive translation breaks on Iceberg tables or silently changes a
result. `auto` rows are proven by `scripts/tests/test_iceberg_tool.py` (`[IB-nn]` tags);
`check_rule_coverage.py --catalog references/corner-cases.md --prefix IB` fails the self-test
otherwise. Facts verified against the Iceberg specification, the Amazon Athena user guide and
the AWS Glue developer guide (2026).

## Engine features Iceberg does not have (record, never drop silently)

| ID | Construct | Treatment | Test |
|---|---|---|---|
| IB-01 | `IDENTITY(seed, step)` | no identity: key generated by the load (`monotonically_increasing_id()` is not stable across runs; use a sequence table or a hash) — ledger row, manual review | auto |
| IB-02 | PK / UNIQUE / FK / CHECK | not enforced and not declared in Athena or Spark DDL; uniqueness proven by `V-014`, referential integrity by `V-018`, domains by `V-009` | auto |
| IB-03 | column `DEFAULT` | applied in the load job (`coalesce(col, default)`); ledger row | auto |
| IB-04 | computed columns (`AS expr PERSISTED`) | computed in the load job or in the serving view | auto |
| IB-05 | clustered / non-clustered / filtered indexes | write-order candidates (`WRITE ORDERED BY`) and partition candidates; nothing created | auto |
| IB-06 | triggers, stored procedures, functions | no procedural engine: Glue job (template) or keep on Aurora; flag `PARTIAL` | auto |
| IB-07 | cursors, table variables, `WHILE` loops | set-based Spark SQL / DataFrame; flag | auto |
| IB-08 | `FOR XML`, `OPENJSON`, XML methods | `to_json`/`from_json`/`get_json_object` (Spark), `json_extract` (Athena); XML manual | auto |

## Table design

| ID | Situation | Rule | Test |
|---|---|---|---|
| IB-30 | partitioning | only from the design file (`year/month/day/hour(col)`, `bucket(N, col)`, `truncate(L, col)`); Spark spelling `years/months/days/hours`; none → unpartitioned with a ledger row | auto |
| IB-31 | location and catalog | Athena `LOCATION 's3://…/'` from the design file (placeholder + `PARTIAL` otherwise); Spark `glue_catalog.db.table` | auto |
| IB-32 | table properties | `table_type=ICEBERG`, `format=parquet` (Athena); `format-version=2`, parquet + zstd (Spark); `write.delete.mode=merge-on-read` for MERGE-heavy tables | auto |
| IB-33 | write order | index columns → `WRITE ORDERED BY` candidates in the ledger | auto |
| IB-34 | identifiers | lower-case snake_case (Glue catalog folds to lower case); `[brackets]` removed | auto |
| IB-35 | schema evolution | in-place promotions `int→long`, `float→double`, `decimal(p,s)→decimal(p+,s)`; other changes = new column + backfill (`schema-change-propagation`) | auto |
