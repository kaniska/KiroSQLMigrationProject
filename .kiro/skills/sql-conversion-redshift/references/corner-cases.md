# Corner-case catalog: SQL Server → Amazon Redshift

Each row is a construct where a naive translation breaks on Redshift or silently changes a
result. `auto` rows are proven by `scripts/tests/test_redshift_tool.py` (`[RS-nn]` tags);
`check_rule_coverage.py --catalog references/corner-cases.md --prefix RS` fails the self-test
otherwise. Facts verified against the Amazon Redshift Database Developer Guide (2026).

## Unsupported on Redshift (route or redesign)

| ID | Construct | Why it fails | Rule | Test |
|---|---|---|---|---|
| RS-01 | `CREATE TRIGGER` | no triggers | flag `PARTIAL`; logic moves to the load job or Aurora | auto |
| RS-02 | table-valued function (`RETURNS TABLE`, `RETURNS @t TABLE`) | UDFs return one scalar (SQL, Python-deprecated after 2026-06-30, Lambda) | rewrite as a view, a procedure with a temp-table result, or keep on Aurora | auto |
| RS-03 | `DECLARE @t TABLE`, table-valued parameters | no table variables/types | `CREATE TEMP TABLE` | auto |
| RS-04 | `CHECK` constraint | unsupported | drop with a ledger row; validate with a query | auto |
| RS-05 | `CREATE SEQUENCE`, `NEXT VALUE FOR`, `SERIAL` | no sequences | `IDENTITY` (not contiguous) or a key generated upstream | auto |
| RS-06 | `FOR XML`, `FOR JSON`, `OPENJSON`, `.value()`, `.nodes()` | no XML methods | `SUPER` + `JSON_PARSE`/`JSON_EXTRACT_PATH_TEXT`; XML stays manual | auto |
| RS-07 | nested cursors, more than one open cursor, cursor outside a transaction | one cursor per session, inside a transaction | set-based rewrite; result via `INOUT refcursor` | auto |
| RS-08 | `INSTEAD OF` views, updatable views | views are read-only | write to tables, keep a read view | auto |
| RS-09 | linked servers, `OPENQUERY`, four-part names, CLR, `xp_` | no equivalent | federated query / Spectrum design decision | auto |

## Functions and expressions

| ID | T-SQL | Redshift | Note | Test |
|---|---|---|---|---|
| RS-10 | `GETDATE()`, `DATEADD(d, n, ts)`, `DATEDIFF(d, a, b)`, `CHARINDEX`, `LEN`, `TOP n`, `CONVERT(type, x)`, `DATEPART`, `#temp` | **kept as is** | ledger row "kept"; `DATEADD('m', …)` is minutes in Redshift, `month` is months | auto |
| RS-11 | `ISNULL(a, b)` | `NVL(a, b)` / `COALESCE` | NVL is a synonym of COALESCE | auto |
| RS-12 | `IIF(c, a, b)` | `CASE WHEN c THEN a ELSE b END` | or `DECODE` | auto |
| RS-13 | `STRING_AGG(x, ',') WITHIN GROUP (ORDER BY k)` | `LISTAGG(x, ',') WITHIN GROUP (ORDER BY k)` | result ≤ 65535 bytes; several LISTAGGs must share the ORDER BY | auto |
| RS-14 | `'a' + b`, `N'text'` | `'a' \|\| b`, `'text'` | `\|\|` with NULL yields NULL (same as SQL Server default) | auto |
| RS-15 | `NEWID()`, `NEWSEQUENTIALID()` | none | key generated upstream or `MD5(…)` surrogate; flag | auto |
| RS-16 | `OBJECT_ID()`, `@@ROWCOUNT`, `SCOPE_IDENTITY()`, `@@IDENTITY` | none / `GET DIAGNOSTICS n := ROW_COUNT` (procedures) | catalog queries against `SVV_*` / `PG_*` | auto |
| RS-17 | `[Bracketed Identifiers]`, mixed-case names | unquoted lower-case | Redshift folds identifiers to lower case | auto |
| RS-18 | `SET NOCOUNT ON`, `WITH (NOLOCK)`, `OPTION (…)`, `GO`, `USE` | removed | no hints on Redshift | auto |
| RS-19 | `TRY_CAST`, `TRY_CONVERT` | none | `CASE WHEN … ~ '^[0-9]+$' THEN CAST … END` or `CAN_JSON_PARSE`-style guards | auto |

## Table design and constraints

| ID | Situation | Rule | Test |
|---|---|---|---|

## Procedures

| ID | Situation | Rule | Test |
|---|---|---|---|
| RS-40 | procedure returning result sets | `INOUT refcursor` argument (`CALL p(1, 'cur'); FETCH ALL FROM cur;` inside a transaction) or a temp table the caller reads | auto |
| RS-41 | `BEGIN TRAN … COMMIT`, `SET XACT_ABORT ON` | implicit transaction per call (atomic mode); `COMMIT` inside only when not called in a transaction block; `NONATOMIC` when each statement must commit | auto |
| RS-42 | `BEGIN TRY … CATCH`, `THROW`, `RAISERROR` | `EXCEPTION WHEN OTHERS` is limited (no subtransactions); `RAISE EXCEPTION`; re-`RAISE` only in NONATOMIC | auto |
| RS-43 | `sp_executesql`, `EXEC (@sql)` | `EXECUTE cmd` with `quote_ident`/`quote_literal`; no variable substitution inside the string | auto |
| RS-44 | `OUTPUT` parameters | `INOUT` (required when nested); ≤ 32 in / 32 out arguments | auto |
| RS-45 | `WHILE … FETCH` loops | set-based rewrite; loops only for control flow | auto |
| RS-46 | `RETURN @code` | no return value: `INOUT p_return_code` or `RAISE` | auto |

## DML and views

| ID | Situation | Rule | Test |
|---|---|---|---|
| RS-50 | `MERGE … WHEN MATCHED AND cond THEN … WHEN NOT MATCHED BY SOURCE` | Redshift MERGE has one `WHEN MATCHED` (UPDATE or DELETE) and one `WHEN NOT MATCHED` (INSERT), no `WITH`, source ≠ target → split into UPDATE/DELETE + INSERT | auto |
| RS-51 | MERGE source with duplicate keys | "Found multiple matches" error → deduplicate the source (`ROW_NUMBER() … QUALIFY rn = 1`) | auto |
| RS-52 | view over external (Spectrum) tables or over tables that get rebuilt | late-binding view: `WITH NO SCHEMA BINDING`, every object schema-qualified, no recursive CTE | auto |
| RS-53 | recursive CTE | `WITH RECURSIVE cte(col, …) AS (…)`: column list required, no ORDER BY/LIMIT in the recursive member; not allowed in late-binding views or subqueries | auto |
| RS-54 | `UPDATE t SET … FROM t JOIN …`, `DELETE t FROM t JOIN …` | `UPDATE t SET … FROM s WHERE …`, `DELETE FROM t USING s WHERE …` | auto |
| RS-55 | `SELECT INTO #t` | `CREATE TEMP TABLE t AS SELECT …` | auto |
| RS-56 | `TOP n` together with `LIMIT` | not allowed in one query | auto |
| RS-57 | window filter via subquery on `ROW_NUMBER()` | `QUALIFY` clause (FROM alias required) | auto |

## Collation, security, execution

| ID | Situation | Rule | Test |
|---|---|---|---|
| RS-60 | case-insensitive `=`/`LIKE` (`_CI_AS`) | `COLLATE CASE_INSENSITIVE` (database or column) decided at design, or `LOWER()` both sides; cannot mix collations in one query | auto |
| RS-61 | identity functions / authorization joins in views | `CREATE RLS POLICY … USING (…)` + `ATTACH … TO ROLE`; masking via `CREATE MASKING POLICY`; needs approved identity mapping (SECURITY_MAPPING_REQUIRED) | auto |
| RS-62 | `COPY … CREDENTIALS 'aws_access_key_id=…'`, `UNLOAD … TO 's3://…'`, `CREATE EXTERNAL SCHEMA`, `CREATE USER … PASSWORD` | credentials in SQL are refused (SEC-03); data exfiltration and identity changes are blocked in generated code (SEC-04) | auto |
| RS-70 | execution evidence | `redshift_tool.py run` uses the Redshift Data API (`batch-execute-statement`, ≤ 200 KB) against a test/dev/sandbox database only, after a security scan; otherwise V-004 stays unexecuted | auto |
